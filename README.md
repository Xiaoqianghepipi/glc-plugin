# glc-plugin

![插件图标](icon.png)

glc-plugin 是一个为 Yunzai-Bot 开发的 归龙潮（果粒橙） 游戏插件

## 功能

- `&[角色名]攻略`：读取本地攻略图并发送。
- `&帮助` 或 `#归龙潮帮助`：渲染帮助图并发送。
- `#归龙潮设置渲染精度 100` 或 `&设置渲染精度 100`：设置图片渲染精度（50~200%）。
- `#归龙潮查看渲染精度` 或 `&查看渲染精度`：查看当前图片渲染精度。
- `#归龙潮更新` 或 `&更新`：拉取插件最新代码并提示更新结果，仅管理员可用。
- 支持使用锅巴配置设置
